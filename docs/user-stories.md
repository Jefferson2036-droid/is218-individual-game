# Five user stories

Drafts that cover the required flow. Rewrite each one for the chosen concept and audience.

1. **Account.** As a new player, I want to create an account and log in, so that my results belong to me.
   - Accept: registering with a valid email and password creates a user; a duplicate email is rejected; a wrong password does not log in.
2. **Game.** As a logged-in player, I want to play a round of ___, so that ___.
   - Accept: a round can be started and finished in the browser; (concept-specific rule).
3. **Saved result.** As a player, I want my result saved when a round ends, so that I do not lose it.
   - Accept: finishing a round stores one result linked to my account; the result is still there after logging out and back in.
4. **Dashboard.** As a returning player, I want a dashboard of my past results, so that I can see my progress.
   - Accept: the dashboard lists only my results; it shows (best / most recent / count); it handles having no results yet.
5. **Account update.** As a player, I want to update my display name and password, so that my account stays current.
   - Accept: a changed display name appears on the dashboard; a new password works on next login and the old one does not.
