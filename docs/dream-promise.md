# Dream, Working Promise and Experiment

Decided 2026-11-23.

## Dream (bigger than this term)
Arena Climb as a full ranked game: customizable fighters, daily runs, a friends leaderboard, maybe animated 3D fighters. See the [backlog](backlog.md).

## Working Promise (must work by the Dec 6 final)
A player **signs up** → plays a **best-of-5 match** against the computer at their rank → the result and stars are **saved** → their **private dashboard** shows rank, progress to the next rank, wins/losses/ties, streak and recent matches (with an empty state for new players) → they **change their display name and password** (password change requires the current password).

Out of this promise: coins, gear, armory, daily runs, multiplayer.

## Creative experiment
"Almost there" nudge, an A/B test. Details in [experiment.md](experiment.md).

## Code pattern experiment
Strategy pattern for the computer opponent, compared with a single if/else function. Details in [pattern-experiment.md](pattern-experiment.md).
