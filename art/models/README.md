# Models

Put one model file per fighter here, named:

- `knight.glb` (or `.gltf`, `.fbx`, `.obj`)

## Where they come from
Planned source: free CC0 (public domain) low-poly characters by Quaternius:
- LowPoly RPG Characters (wizard, warrior, rogue, monk, ranger): https://opengameart.org/content/lowpoly-rpg-characters
- (Not used: LowPoly Animated Knight — the RPG pack's Warrior is used instead so all three fighters match.)
